# StationFlow

Første fungerende frontend-versjon av StationFlow, laget med Next.js, TypeScript og Tailwind.

## Innhold

- Leder-dashboard med digital uke-/månedsvaktplan
- Ansatte som rader og datoer som kolonner
- Vaktkoder som oversettes til tider
- Fri, ferie, fravær og ledige vakter
- Klikkbare vakter med detaljpanel
- Vaktmaler som leder kan velge fra
- Enkel ansattvisning med Mine vakter, stempling og oppgaver

## Kjør lokalt

```bash
npm install
npm run dev
```

Åpne `http://localhost:3000`.
